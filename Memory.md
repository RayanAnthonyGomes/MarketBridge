## 🔑 Key Decisions Made

| # | Decision | Rationale | Date |
|---|----------|-----------|------|
| 1 | 5-phase prototype build approach | Validates design and UX before investing in backend infrastructure | 2026-07-30 |
| 2 | Inter + Outfit font pairing | Inter for UI readability, Outfit for display headers. Free Google Fonts. | 2026-07-30 |
| 3 | Royal Indigo (`#4F46E5`) as primary color | Trust and professionalism for a marketplace. Works in light + dark mode. | 2026-07-30 |
| 4 | Dark mode as first-class citizen | Modern expectation. Designed from scratch, not bolted on. | 2026-07-30 |
| 5 | Lucide React for iconography | Open source, 1.5px stroke, tree-shakeable, actively maintained. | 2026-07-30 |
| 6 | **PIVOT to frontend-only prototype** | User wants to validate frontend design first. No Docker, backend, or real auth needed. All data is mock. 3 dummy users for role-based demo. | 2026-07-30 |
| 7 | Vite over CRA | Faster dev server, smaller bundle, modern defaults. CRA is deprecated. | 2026-07-30 |
| 8 | Vanilla CSS with custom properties (no Tailwind) | Maximum control over design system. Dark/light mode via CSS custom properties. | 2026-07-30 |
